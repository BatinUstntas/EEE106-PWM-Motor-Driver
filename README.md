# 220VAC - 24VDC 30W Motor Driver Circuit Design

This repository contains the academic final project developed for the **EEE 106 - Computer Aided Circuit Design** course at Ostim Technical University. The project documentation and technical report are provided in English.

## 📌 Project Overview
In this study, based on a provided reference schematic, a motor driver circuit that converts 220VAC mains voltage to a 24VDC / 30W output was modeled. The system aims to efficiently control motor speed using the PWM (Pulse Width Modulation) technique, utilizing an NE555 Timer and an IRLZ44N Logic-Level MOSFET.

## 🛠️ Tools and Technologies
* **Proteus ISIS:** Electrical schematic capture and virtual simulation testing.
* **Proteus ARES:** Single/double-layer PCB layout design and routing optimization compliant with IPC-2221 standards.
* **Hardware Components:** NE555 Precision Timer, IRLZ44N MOSFET, LM7824 Voltage Regulator.

## 📁 Repository Contents
This repository includes the following directories and files:
* **`/3D_Models`** - Custom 3D STEP models and design files for components (potentiometer, DPDT switch, terminal blocks, etc.) used in the PCB.
* **Proteus Files** - Source files for electrical simulation (ISIS) and PCB routing (ARES).
* **Comprehensive Technical Report** - A 40-page academic engineering report detailing all calculations, design choices, and simulation-to-reality comparisons (Duty Cycle 8% - 92%).
* **Visuals** - High-resolution 3D rendered images and PDF outputs of the circuit design.
